# 👥 Учёт сотрудников

> Практическая работа №2 · Spring Boot · Java 17

Простое веб-приложение для ведения списка сотрудников организации.

## 👨‍🎓 Данные студента

| Поле | Значение |
|---|---|
| **ФИО** | Усков Роман Владимирович |
| **Группа** | ИС-11-24-2 |

## ✨ Возможности

- 📋 просмотр списка сотрудников;
- 🔎 поиск по ФИО;
- 🟢 фильтрация по активности;
- ➕ добавление нового сотрудника;
- ✏️ редактирование данных;
- 🗑️ удаление сотрудника;
- ✅ валидация введённых данных;
- 📧 проверка уникальности email.

## 🛠️ Технологии

| Технология | Назначение |
|---|---|
| Java 17 | язык программирования |
| Spring Boot | основа приложения |
| Spring Data JPA | работа с базой данных |
| Thymeleaf | HTML-шаблоны |
| H2 | база данных |
| Maven | сборка проекта |

## 📁 Структура проекта

```text
src/main
├── java/.../controller   # обработка HTTP-запросов
├── java/.../model        # сущность Employee
├── java/.../repository   # доступ к данным
├── java/.../service      # бизнес-логика
└── resources
    ├── templates         # HTML-страницы
    └── static             # CSS-стили
```

## ▶️ Запуск

Убедитесь, что установлены **Java 17+** и **Maven**.

```bash
mvn spring-boot:run
```

Откройте приложение в браузере:

```text
http://localhost:8080/employees
```

## 📦 Сборка

```bash
mvn clean package
```
